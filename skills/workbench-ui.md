# workbench-ui：DSH Ren'Py 开发工作台 · 界面样式设计规范

> 用途：RenPy 工作台（RenpyPanel）UI 大更的风格基准——**功能代码由开发者自写，本规范只约束"长什么样"**。
> 目标风格：类 **VS Code**（活动栏 + 侧栏 + 编辑器区 + 面板区 + 状态栏）+ 类 **Adobe**（面板可停靠/浮动/标签组、工作区预设）。
> 全部颜色/字体必须引用 DSH 主题 token（`var(--…)`），随亮暗主题自动适配，禁止硬编码色值。

---

## 一、设计原则

1. **内容优先**：界面服务于编辑/调试内容，装饰最小化；大面积留白由数据密度决定，不额外堆视觉元素。
2. **分层克制**：层级用背景色差 + 边框线表达（最多 4 层：base → layer1 → layer2 → 浮层），不靠投影堆层次。
3. **单强调色**：品牌色（`--dsw-alias-brand-primary`）只用于：选中态、主按钮、激活导航、聚焦框线。其余状态用语义色（成功/警告/错误/信息）。
4. **密度中高**：默认紧凑控件（高度 24-26px），信息密度对齐 VS Code 默认；大屏可切换宽松密度（见 §2）。
5. **一致性 > 个性**：同类控件全局同尺寸同状态；不出现"这页圆角 4、那页圆角 10"。

## 二、工作台布局规范

### 骨架（VS Code 式）
```
┌────────────┬────────────────────────────────┬────────────┐
│ 活动栏 46-172px │ 侧栏左(文件/导航/素材/基线)   │ 侧栏右(对话/调试)│
│ 图标垂直列  ├────────────────────────────────┤            │
│            │ 中央区：编辑器组 + 内部分栏        │            │
│            ├────────────────────────────────┤            │
│            │ 底部面板区(日志, 可拖高)           │            │
├────────────┴────────────────────────────────┴────────────┤
│ 状态栏 24px：当前位置 | 运行状态 | 桥接状态 | 光标行/列      │
└──────────────────────────────────────────────────────────┘
```
- 活动栏：宽 **46px**（收起）/ **172px**（展开，图标+文字），图标 20px，垂直排列；靠近展开/离开自动收起；底部「«」手动切换。
- 侧栏左：默认宽 **220px**（可拖 140-560），面板垂直堆叠，标题栏 26px（面板名 + 操作 + ⛶最大化 + ✕移除）。
- 侧栏右：默认宽 **220px**（可拖 140-560），**对话默认停靠于此**，调试面板（路线图/画面/变量）点击导航栏也停靠右侧；空时不占空间。
- 底部面板：默认高 **170px**（可拖 80-600），面板水平排布；顶部 4px 拖拽条调高。
- 分栏拖动条：4-5px 宽，hover 品牌色高亮，拖拽严格跟手（像素级换算）。
- 面板关闭后显示"空状态"（居中小图标 + 提示文字，§6）；面板移除后可从导航栏重开。

### 间距与密度
| 密度 | 控件高 | 行高 | 间距基准 | 适用 |
|---|---|---|---|---|
| 紧凑（默认） | 24px | 22px | 4px | 文件树/表格/工具条 |
| 标准 | 28px | 24px | 4px | 按钮/输入/标签页 |
| 宽松（可切换） | 32px | 28px | 6px | 无障碍/大屏 |

- 间距一律用 **4px 栅格**（4/8/12/16/24）；面板内边距 8-12px；卡片/浮层内边距 12-16px。
- 圆角：控件 **6px**，浮层/弹窗 **10px**，标签胶囊 **12px**，图标按钮 6px。全局统一，不逐处自定义。

## 三、色彩系统（全部走 token）

### 分层映射
| 语义 | token | 用法 |
|---|---|---|
| 基底背景 | `--dsw-alias-bg-base` | 工作台根、编辑器区、空白处 |
| 层 1 | `--dsw-alias-bg-layer-1` | 侧栏、面板、标题栏、弹窗头 |
| 层 2 | `--dsw-alias-bg-layer-2` | 输入框、代码块、hover 块 |
| 侧栏填充 | `--dsw-specific-sidebar-fill` | 侧栏专属底色（比 layer1 略偏） |
| 边框 1 | `--dsw-alias-border-l1` | 常规分隔、控件描边 |
| 边框 2 | `--dsw-alias-border-l2` | 强调分隔、hover 描边、面板边界 |

### 文本
| 语义 | token | 用法 |
|---|---|---|
| 主文本 | `--dsw-alias-label-primary` | 标题、正文、代码前景 |
| 次文本 | `--dsw-alias-label-secondary` | 说明、值、次要信息 |
| 弱文本 | `--dsw-alias-label-tertiary` | 占位符、禁用、时间戳、辅助 |

### 强调与状态（唯一的功能色）
| 语义 | token | 用法 |
|---|---|---|
| 品牌/强调 | `--dsw-alias-brand-primary` | 选中、主按钮、激活、聚焦、链接 |
| 成功 | `--dsw-alias-state-success-primary` | lint 通过、已保存、新增、运行中 |
| 错误 | `--dsw-alias-state-error-primary` | lint 错误、失败、冲突 |
| 业务/警告 | `--dsw-alias-state-business-primary` | 警告、待确认、外部修改 |
| 幽灵按钮底 | `--dsw-alias-button-ghost-active-fill` | 幽灵按钮激活态填充 |
| hover 底 | `--dsw-alias-interactive-bg-hover` | 行/项 hover 底色 |

### 颜色使用铁律
- 状态色只表达**状态**（成功/错误/警告），不与强调色混用表达"选中"。
- 禁用态：文本降三级 + 控件降透明度（0.45），不用灰色硬编码。
- 功能图（路线图）允许语义专色：结局绿 / 起点蓝 / 选择紫 / 死路红 / 孤立灰 / 循环黄（沿用现有路线图配色，仅此一处豁免）。

## 四、字体与排版

| 用途 | 字体 | 基础字号 | 说明 |
|---|---|---|---|
| UI 文本 | `--dsw-font-family` | 13px | 按钮/标签/标题 13px；辅助 11-12px |
| 代码/值 | `--ds-font-family-code` | 12px | 编辑器/日志/变量值/路径 |
| 大标题 | UI | 14-16px 600 | 面板标题、弹窗标题 |

- 行高：文本 1.5（20px）；代码 1.6；紧凑行 22px 固定。
- 强调：只用字重（600）+ 品牌色，**不用斜体/下划线**表达强调（下划线仅链接）。

## 五、控件规范

### 图标系统（codicon 内嵌 SVG）

- **来源**：VSCode 官方 codicon 图标（MIT，`client.js` 内嵌 37+ 个 SVG path，从 `codicon.ttf` 提取，viewBox 按各图标轮廓归一）。
- **渲染**：统一走 `Ico` 组件（`<Ico name size className style>`），`fill: currentColor` —— **图标颜色跟随所在按钮/文字的主题色**，禁止给图标硬编码颜色。
- **命名约定**（控件栏图标映射，改图标只改这里）：
  - 编辑工具：`text-size`（样式预览）/ `arrow-swap`（Python 对照）/ `book`（学习）/ `color-mode`（GUI 主题）
  - 调试面板：`graph`（路线图）/ `device-camera-video`（实时画面）/ `symbol-variable`（变量）/ `bug`（报错）/ **`checklist`（静态诊断——用清单勾选，不用 `search` 放大镜以免与搜索混淆）**
  - 视图：`files` / `compass` / `collection` / `edit`
  - 面板：`list-unordered`（日志）/ `history`（历史）/ `gear`（设置，**固定在控件栏底部**）
  - 工具栏：`play`/`debug-stop`（运行/停止合一）/ `warning`（检查）/ `beaker`（测试）/ `refresh` / `save` / `device-camera`（截图）/ `comment-discussion`（对话）/ `location`（工作范围）
  - 标题栏：`gripper`（拖拽手柄，最左）/ `chrome-maximize`/`chrome-restore` / `close`
  - 素材：`file-media`（图片）/ `music`（音频）/ `device-camera-video`（视频）/ `text-size`（字体）/ `file`（其他）；导航：`tag`/`person`/`sync`/`symbol-variable`/`text-size`
- **保留字符**：树折叠箭头 `▾/▸`、面板分组标题文字（`⚙ 功能`/`🎨 控件`）、日志文本 emoji（addLog 纯文本不换图标）。

> 美术基调（§5.1）：**统一 1px 描边 + 投影**——所有可交互控件 idle 即带描边（边框 l2）与轻投影（0 1px 2px rgba(0,0,0,.18-.22)）；主按钮彩色投影（0 1px 3px rgba(0,0,0,.35)）；输入框内阴影（inset 0 1px 2px rgba(0,0,0,.18)）。亮暗主题阴影强度随 token 适配。

| 控件 | 尺寸/圆角 | 状态（idle→hover→active→disabled） |
|---|---|---|
| 按钮（标准） | 高 26px，padding 10-14px，圆角 6px | 底 layer2 + 描边 l2 + 投影 → hover 边框 l2/底色加深 → 按下内压 1px → 禁用 opacity .45 |
| 按钮（主） | 同标准 | 底 brand + 白字 + 彩色投影 → hover 亮度微调 → 禁用降透明度 |
| 按钮（图标） | 26×26，透明描边 + 轻投影 | hover 底 `interactive-bg-hover` → active 底 `button-ghost-active-fill` |
| 输入框 | 高 26px，圆角 6px，padding 6-8px | 底 layer2 + 描边 l2 + 内阴影 → 聚焦边框 brand（1.5px）→ 禁用降透明度 |
| 标签页 | 高 30px，padding 8-12px | 底透明 → hover layer2 → 激活底 layer2+ 顶缘 2px brand 指示 |
| 下拉 | 高 26px | 同输入框；弹出项高 26px，选中项底 brand 10% 透明度 |
| 树/列表行 | 高 22-24px，圆角 5px，缩进 14px/级 | hover `interactive-bg-hover` → 选中底 `button-ghost-active-fill` + 文本品牌色 |
| 表格 | 行高 24px，表头 13px 600 三级色 | 分隔线 l1；hover 行底；选中行底 ghost 填充 |
| 徽标/状态点 | 高 16px 胶囊，字号 10px | 语义色底 15% 透明度 + 语义色文本 + 轻投影 |
| 工具提示 | 浮层 bg-base + 边框 l2 + 阴影，字号 12px | 延迟 300ms 显示 |
| 滚动条 | 宽 8px，thumb 圆角 4px | thumb = 三级文本 20% 透明度，hover 40% |

## 六、面板与窗口规范（Adobe 式可停靠）

- **面板头**：高 30px，层 1 底 + 下边框 l1；左侧面板名（13px 600），右侧操作（图标按钮）。
- **面板控件注册表**：文件/导航/素材/基线更改/日志/对话/路线图/实时画面/变量监控——全部为**可停靠面板控件**：左/右/下分区平铺、标题栏拖拽吸附、拖出成浮动窗；区域与浮动窗共用同一内容渲染。
- **停靠区域与默认位置**：
  - 左侧栏（垂直堆叠）：文件、导航、素材、基线更改
  - **右侧栏（垂直堆叠）：对话（默认）、路线图、实时画面、运行时变量**（调试面板点击导航栏停靠右侧）
  - 底部区（水平排布）：日志
  - 区域空时不占空间（让位给编辑器）；默认布局持久化到 localStorage.renpy-panel-layout，旧布局自动迁移（nav 拆分、对话移右侧）
- **区域/比例拖拽**：左右栏外缘拖拽条调宽、底部区上缘拖拽条调高、区域内面板间分隔条调比例——全部像素级跟手（按位移×总权重/区域尺寸换算），hover 品牌色高亮，拖出 iframe 失焦自动取消。
- **面板最大化**：标题栏 ⛶ 占满整个工作区（隐藏导航/区域/侧栏），🗗 还原；移除面板自动取消最大化。
- **标签组**：横排标签，激活标签顶缘 2px brand 指示；未保存标记 ●（错误色）。
- **停靠预览**：拖拽面板时，目标区 3px brand 虚线框 + 中心/四边落点高亮（半透明 brand 10%）；**插入位置指示线 4px brand + 发光**（0 0 8px brand），换序落点一目了然；**目标区域无面板（未渲染）时，视口边缘显示 4px 发光条**提示落点。
- **拖拽 ghost**：面板轮廓预览（220×96，半透明 brand 底 + brand 描边 + 标题栏 + 虚线内容区），源面板拖拽中降透明（opacity .35）。
- **浮动窗口**：投影（0 8px 24px rgba(0,0,0,.3)）、圆角 10px、可拖可缩放（右下 18px 把手）、Esc 关闭；标题栏可拖。
- **空状态**：居中对齐，图标 32px 三级色，说明 13px 次级色，间距 8px。
- **工作区预设**：工具栏下拉切换（默认/调试/编辑），布局序列化 JSON 存 localStorage。

## 七、动效与反馈

| 场景 | 规则 |
|---|---|
| hover/激活 | 150ms ease 颜色过渡；不移动元素 |
| 面板停靠预览 | 200ms 高亮淡入 |
| 浮层打开 | 100ms 淡入 + 微缩放（0.98→1）；关闭 100ms 淡出 |
| 拖拽 | 无过渡（跟手）；松手 100ms 吸附 |
| 变化反馈（变量/日志） | 新增闪绿、修改闪蓝，1.5s 后还原（禁止长亮动画） |

## 八、明暗适配

- 所有颜色必须走 token——亮暗主题自动切换，**禁止在 JSX/CSS 里写死色值**（路线图专色等豁免需注释说明）。
- 阴影/透明度随主题：亮色弱投影、暗色强投影；代码编辑器固定深色（`#1e1e1e` 系列，VS Code 惯例）。

## 九、禁止事项（对照检查）

1. ✗ 硬编码颜色/字号/间距（必须 token + 4px 栅格）
2. ✗ 每个功能自造一套按钮样式（必须走 §5 控件规范）
3. ✗ 状态色当强调色用（选中=品牌色，成功/错误≠选中）
4. ✗ 弹窗/浮层塞满全屏内容（应可停靠到面板区）
5. ✗ 无空状态的空白区域（必须给居中原型提示）
6. ✗ 阴影堆叠超过一层（层次用背景差 + 边框，不用多层投影）
