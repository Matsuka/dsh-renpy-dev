# DSH Ren'Py 开发工作台 — 测试用户功能手册

> 本文档面向**测试用户**：不要求懂代码，按步骤操作、对照预期结果即可完成全部功能的验证。
> 每个功能都按「**在哪里 → 怎么操作 → 预期看到什么 → 测什么**」四段式说明。
>
> 配套阅读：部署见 `DEPLOY.md`，界面规范见 `skills/workbench-ui.md`。

---

## 0. 快速开始（5 分钟上手）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 在 DSH Web 界面（`http://127.0.0.1:3080`）新建会话，preset 选「RenPy Dev」 | 出现新会话 |
| 2 | 会话上方找到 **「Ren'Py」页签**并点击 | 打开开发面板 |
| 3 | 顶部输入框填入项目路径（含 `game/` 目录的项目根，如 `D:\my-game`），回车或点 **⟳** | 左侧出现文件树、中间出现编辑器 |
| 4 | 点开 `game/script.rpy` | 编辑器打开，代码带彩色语法高亮 |
| 5 | 顶栏点 **⚠ 检查** | 下方出现「lint 通过」 |

> **没有项目？** 在对话里对 AI 说「帮我新建一个测试项目」即可（AI 会用 `renpy_scaffold` 生成）。

## 2. 顶栏工具栏（每个按钮）

工具栏从左到右：

| 按钮 | 名称 | 操作 | 预期 | 测试要点 |
|---|---|---|---|---|
| 项目路径输入框 | 项目 | 输入 Ren'Py 项目根目录（含 `game/`），回车 | 加载文件树/资源 | 换一个项目再加载，内容整体切换 |
| **⟳** | 默认工程 | 点击 | 自动填入 host 配置的默认工程路径 | 配置过默认工程时一键切换 |
| **🎯 工作范围** | 锁定编辑范围 | 先在编辑器**选中几行**（或光标停在某行），再点它 | 编辑器出现**绿色高亮区域**；按钮旁出现「✖ 清除」 | 区域外打字被拦截；见 §8 |
| **▶ / ■** | 运行/停止（合一） | 未运行时点它 → **运行游戏**；运行中点它 → **停止** | 游戏窗口弹出；按钮变红色「■ 停止游戏」；再点停止 | 运行后按钮状态切换；游戏自己关闭后按钮自动变回 ▶ |
| **⚠ 检查** | lint 语法检查 | 点击 | 下方显示 lint 结果；有错的行编辑器内**红色下划线** | 故意删掉一个冒号再检查，应报错定位 |
| **🧪 测试** | 自动化测试 | 项目含 testsuite 时点击 | 运行 rpytest，报告条显示 ✓/✗ | demo 项目应全通过 |
| **⟳ 刷新** | 刷新文件列表 | 点击 | 重新扫描 `game/`，新文件出现 | 在项目里新建 .rpy 后点刷新 |
| **💾 保存** | 保存当前文件 | 点击（或 `Ctrl+S`） | 状态栏变 ✓；有改动时**每次保存自动备份** | 见 §6 历史 |
| **📷 截图** | 整屏截图 | 游戏运行中点击 | 保存当前屏幕为 PNG，对话/面板可查看 | 游戏画面变化后再截，图应不同 |
| **💬 对话** | 打开对话面板 | 点击 | 右侧栏出现对话面板（含消息流/检查点时间线/轨迹） | 与 AI 对话见 §11 |

## 3. 控件栏（左侧竖条）

鼠标悬停每个图标会弹出右侧说明；图标下文字在展开状态显示。自上而下分组：

### 3.1 编辑工具（作用于编辑器）

| 图标 | 功能 | 操作 | 预期 |
|---|---|---|---|
| **Aa** | 样式预览 | 打开含对白文本的文件 → 点击（再点关闭） | 对白文本**直接按样式渲染**：`{b}` 粗体、`{color}` 变色、`{size}` 放大、`{font}` 换字体、插值 `[x]` 黄色标记；行高自动放大 |
| **⇄** | Python 对照 | 光标停在某条语句（如 `show eileen happy`）→ 点击 | 右下角浮窗显示该语句的 Python 等价（如 `renpy.show(...)`）+ 语义说明 |
| **📖 学习** | AI 学习注释 | 打开 .rpy → 点击 → 确认弹窗 | AI 为语句行生成 `# 📖 学习: …` 讲解注释写入文件；结果条显示写入条数 + 「清除全部」 |
| **🎨 GUI** | GUI 主题定制 | 打开含 `gui.rpy` 的项目 → 点击 | 面板显示分辨率/主题色/字号，改后「保存到 gui.rpy」写回文件 |

### 3.2 调试面板（需运行游戏；点击后停靠右侧栏）

| 图标 | 面板 | 内容 |
|---|---|---|
| 🗺 | 分支路线图 | 项目 label 状态机图（节点=label，连线=跳转）；点击节点跳游戏（需运行） |
| 🎬 | 实时画面 | 游戏画面截图 + 点击/推进/回滚操作 |
| 📊 | 运行时变量 | 变量实时值监控，变化高亮 |
| 🐞 | 报错诊断 | 项目根目录 `traceback.txt`/`log.txt`/`errors.txt` 结构化解析：崩溃栈/根因/lint 错误，点击 file:line 跳编辑器 |
| ✅ | 静态诊断 | 全项目引用完整性扫描：无效跳转/未定义 screen/角色/缺失资源/不可达 label，点击跳转 |

> **静态诊断 vs lint**：lint 是引擎级权威检查（⚠ 按钮）；静态诊断是秒级快速初检（✅ 按钮），适合频繁自检。

### 3.3 视图控件（停靠左侧栏）

| 图标 | 面板 | 内容 |
|---|---|---|
| 📄 | 项目文件 | `game/` 下所有 .rpy 文件树，点击打开 |
| 🧭 | 导航 | 项目结构索引：标签/人物/转场/变量/字体 五类，点击跳转 |
| 🖼 | 项目素材 | 图片/音频/视频/字体分类树，点击叶子预览 |
| ✎ | 基线更改 | 相对检查点基线的所有文件改动列表 |

### 3.4 面板控件

| 图标 | 功能 |
|---|---|
| 📋 | 操作日志（停靠底部区）：所有操作的时间线记录 |
| 📜 | 保存历史：当前文件所有备份版本，预览/恢复 |
| **⚙** | **个性化设置（固定在底部）**：编辑器/界面颜色/字体等全部配置，见 §12 |

底部还有 **« / »** 按钮：收起/展开控件栏（收起时只显示图标）。

## 4. 编辑器

| 能力 | 操作 | 预期 |
|---|---|---|
| 语法高亮 | 打开 .rpy | 语句蓝、名称黄、字符串橙、注释绿、数字青；**Python 块**（`init python:`/`python early:`/`$ 单行`）内关键词紫、内置类型青、内置函数蓝 |
| 代码补全 | 输入关键字时 `Ctrl+Space` | 语句/角色/资源/代码片段补全面板 |
| 查找替换 | `Ctrl+F` | 查找栏：匹配高亮、Enter/Shift+Enter 导航、替换单个/全部 |
| 括号匹配 | 光标停在括号 | 配对括号高亮 |
| 注释切换 | `Ctrl+/` | 行注释/取消注释 |
| 未保存提示 | 改后不保存 | 编辑器下方出现「未保存修改 +N 行 -M 行 [保存] [撤回修改]」 |
| 外部冲突 | 未保存时 AI 改同一文件 | 提示「外部修改冲突」，本地保留；关标签重开可加载外部版本 |
| 行号模式 | 设置里配置 | relative（相对当前行）/ off |
| 写守卫 | 保存被拦截 | 结构错误（缩进/保留名/重复 label/括号不配对）时弹出「写守卫拦截了保存」+ 错误列表 + 强制保存选项，见 §9 |

## 5. 面板系统（可停靠/拖拽/最大化）

- **标题栏**：左侧 ⠿ 拖拽手柄（按住拖动）、面板图标+名称、右侧操作（刷新/折叠）、⛶ 最大化、✕ 移除
- **拖拽**：按住标题栏拖动 → 拖到左/右/下区域吸附（有高亮预览），或拖出成浮动窗
- **最大化**：⛶ 占满整个工作区；🗗 还原；Esc 关闭弹层
- **浮动窗**：可拖动、右下角可缩放、Esc 关闭
- **移除/重开**：✕ 移除面板，随时可从控件栏重新打开

## 6. 保存历史与回滚

1. 编辑文件 → 保存（`Ctrl+S`）→ **每次保存自动备份**到 `.renpy-user/backups/`
2. 点控件栏 **📜 保存历史**（或工具栏历史）→ 弹层列出该文件所有版本（时间倒序）
3. 点某版本 → 右侧预览内容；点「恢复到该版本」→ 文件还原

**测试场景**：保存 3 次（每次改不同内容）→ 打开历史 → 恢复最早版本 → 文件内容回到最初。

---

## 7. 检查点与修改面板

- **检查点**：每轮 AI 对话自动建立（基线快照），侧栏对话底部有「持久检查点」时间线
- **修改面板**：AI 改过代码后，控件栏 **✎ 修改 (N)** 出现改动数徽标 → 点击打开
  - 按文件列出 `+A -B` 行级 diff；点击跳转编辑器对应行
  - 编辑器左侧 gutter 颜色标记：绿=新增、蓝=修改、红=删除
  - 「通过」= 接受改动推进基线；「撤回」= 还原该文件/全部

**测试场景**：让 AI「给 script.rpy 加一个角色和一句对话」→ 修改面板出现 diff → 「撤回」→ 文件还原 → 再「通过」→ 基线更新。

## 8. 工作范围（安全约束）

1. 编辑器选中几行（或光标停某行）→ 点工具栏 **🎯 工作范围**
2. 出现**绿色高亮区域**；按钮旁出现 **✖ 清除**（点击解除）
3. 约束效果：
   - **区域外编辑被拦截**（输入无效并提示）
   - 对话注入【工作区域】约束消息，**AI 的修改被限定在区域内**，越界会先询问

**测试场景**：锁定 5-10 行 → 在区域外打字被拒 → 让 AI 改文件确认它只动区域内 → 清除后恢复正常。

## 9. 写守卫（保存拦截）

保存 .rpy 时自动校验四类结构错误：

| 类型 | 示例 |
|---|---|
| 缩进错误 | tab/空格混用、label 后语句未缩进 |
| 保留名 | 用 Python 关键字/语句名做 label、变量名 |
| 重复 label | 文件内或跨文件重复定义 |
| 对白括号 | `{ }` 与 `[ ]` 不配对 |

- 发现问题 → 弹「写守卫拦截了保存」+ 错误列表（含行号）
- 可「取消（先修正）」回编辑器修改，或「仍要保存（强制）」绕过

**测试场景**：故意写 `label if:`（if 是保留字）→ 保存 → 被拦截并提示。

## 10. 运行与调试

### 10.1 运行/停止
- 工具栏 **▶ 运行游戏** → 真实游戏窗口弹出；按钮变红 **■ 停止游戏**
- 停止后按钮恢复；游戏自行退出（关闭窗口）也会自动恢复
- 运行中可用 **📷 截图** 抓取当前画面（AI 也能看到）

### 10.2 路线图（🗺）
点击后右侧栏出现项目流程状态机图：绿色=结局、蓝色=起点、紫色=选择、红色=死路；运行中点节点跳转游戏。

### 10.3 实时画面（🎬）
游戏运行中显示画面截图；可点击画面（模拟点击游戏）/推进/回滚。

### 10.4 运行时变量（📊）
实时变量值列表，变化高亮闪烁 1.5s。

### 10.5 报错诊断（🐞）
游戏崩溃后读取 `traceback.txt` 等文件：显示崩溃位置/根因/完整栈帧/lint 错误/log 内嵌段；点击任意 file:line 跳到编辑器对应行。

### 10.6 静态诊断（✅）
扫描全部 .rpy 的引用完整性，按类型分组（无效跳转/未定义 screen/未定义角色/缺失资源/不可达 label），error/warn/info 着色，点击跳转。

## 11. 与 AI 协作

- **侧栏对话**：右侧聊天框发送消息；助手消息支持 Markdown 渲染、**🤔 思考**可展开推理、hover 显示「⧉ 复制」；用户消息 hover 显示「✎ 编辑」可改后重发
- **轨迹**：对话下方显示工具调用记录（lint/run/edit 等），编辑类条目显示「✎ 文件名」，点击跳转编辑器对应位置
- **检查点时间线**：对话底部显示每轮检查点，点击可切到任意历史版本查看/恢复
- **学习注释（📖）**：让 AI 给代码逐行讲解，生成注释写入文件（消耗 AI 资源，见 §13）

**测试场景**：发「把 script.rpy 的第一句对白改成‘你好，世界’」→ AI 改完 → 轨迹出现 edit 条目 → 点击跳转到改动行 → 检查点时间线新增。

### 设置生效与存储
- 改动**即时生效**（字号/字体改动会重载编辑器）

- 保存于 DSH 用户目录 `.renpy-user`，**不写入项目目录**

## 15. 已知限制与注意事项

1. **host 改动需重启 dsh**：涉及后端服务（`host.js`）的更新要完全退出 dsh 再启动；只改界面（client）刷新页面即可。
2. **学习注释消耗 AI 资源**：每次生成调用一次模型（批量一次调用），生成可能需数秒至数十秒（90 秒超时保护）。
3. **工作范围是硬约束**：设置后 AI 修改被限定在区域内，改区域外 AI 会先询问——这是设计行为。
4. **打包运行暂不支持**：面板无发布打包按钮（SDK launcher 内部功能）。
5. **备份/检查点不自动清理**：`.renpy-user/backups/`、`checkpoints/` 会累积，需要时手动清理。
6. **写 `init python: import renpy` 会触发引擎异常**（lint 报错），不要写。
7. **部分操作可能触发 DSH 审批提示**（沙箱策略），允许即可。
